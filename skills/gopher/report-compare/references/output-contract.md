# 对比报告输出契约

本文件定义报告的机器可解析 Markdown 结构。所有标题、表头和顺序均为输出协议的一部分。

## 固定结构

```markdown
# 多论文对比分析

用 2-3 句话说明总体共同关注点、最关键差异，以及是否能够直接横向比较实验结果。

## 方法对比表

| 论文 | 研究问题 | 方法路线 | 数据集 | 评价指标 | 实验结论 |
| --- | --- | --- | --- | --- | --- |
| 论文 A | ... [[原文:A.pdf 第 2 页]] | ... | ... | ... | ... |
| 论文 B | ... [[原文:B.pdf 第 3 页]] | ... | ... | ... | ... |

## 相同点总结与分析

...

## 差异分析说明

### 研究目标
...

### 技术路线
...

### 实验设计与可比性
...

### 结论与证据边界
...

## 创新、局限与未来方向

...

## 适用场景与取舍

...
```

## 表格规则

表头必须严格使用以下六列，且顺序不可改变：

1. `论文`
2. `研究问题`
3. `方法路线`
4. `数据集`
5. `评价指标`
6. `实验结论`

每篇输入论文必须对应一行，不得合并两篇论文，也不得增加“综合”行。

每个单元格遵循以下要求：

- 最多写三条短句。
- 多条内容使用 `1. ...；2. ...；3. ...`，保持在同一 Markdown 行。
- 不使用 `<br>`、列表换行、嵌套表格或代码块。
- 内容中的竖线写成中文顿号、逗号或斜杠，不能出现未转义的 `|`。
- 信息缺失统一写 `未抽取`。
- 论文名优先用 `title`，其次 `file_name`，最后 `id`。
- 数据集与评价指标只能从明确的实验或结果描述中提取。
- 具体方法、数据集、指标、数值和实验结论后保留对应论文的原文标签。
- 一个单元格可合并同一论文的多个出处，但不得放入其他论文的出处。
- 每个非空维度用 Markdown `**...**` 加粗 1 到 2 个最重要的区分项，例如关键方法、数据集、指标或结论；不得整格加粗。

## 正文规则

### 总体结论

开头回答三个问题：

- 论文共同研究的核心主题是什么。
- 最大的方法或实验差异是什么。
- 实验结果能否直接比较，为什么。

### 相同点总结与分析

每个共同点至少覆盖两篇论文，并说明共同点的意义。推荐使用以下形式：

```markdown
- **共同研究目标**：论文 A 与论文 B 都关注……；这意味着……
```

### 差异分析说明

必须分为“研究目标、技术路线、实验设计与可比性、结论与证据边界”四个三级标题。若某个维度证据不足，保留标题并明确说明缺失情况。

### 创新、局限与未来方向

把输入中的 `innovations`、`limitations` 和 `future_work` 纳入比较。区分作者明确陈述与基于字段对齐得到的保守分析，不新增输入外的研究建议。

### 适用场景与取舍

逐篇说明更适合的任务、前提和代价。没有足够证据时使用“从当前抽取信息无法判断”，不能用笼统的“各有优劣”结束。

## 禁止项

- 不输出第二个一级标题。
- 不在固定表格前输出其他表格。
- 不把缺失字段解释成负面结论。
- 不伪造页码、引用、指标数值或数据集名称。
- 不把一篇论文的原文标签用于支撑另一篇论文。
- 不输出分析过程、检查清单、模型身份或 skill 调用说明。
